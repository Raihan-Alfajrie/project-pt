# Prompt Kickoff — tempel ini sebagai pesan pertama ke AI agent

---

Kamu akan membangun web dashboard **Pertamina Admin Panel (Rig Monitoring WK Zona 4)**
menggunakan **Laravel 13 + Blade + Alpine.js + Tailwind CSS + MySQL (XAMPP)**.

Sebelum melakukan apa pun, baca dokumen-dokumen berikut **secara berurutan**, semuanya
ada di root folder proyek ini:

1. `AGENTS.md` — aturan kerja kamu. Baca ini paling dulu, ini mengikat semua yang kamu
   lakukan di proyek ini.
2. `PRD.md` — apa aplikasi ini, untuk siapa, dan apa lingkupnya.
3. `DESAIN.md` — bagaimana tampilan & struktur teknisnya harus jadi, termasuk instruksi
   untuk membaca folder `desainku/`.
4. Folder **`desainku/`** — berisi 11 file HTML prototipe (desain final, sudah disetujui).
   Buka dan baca source code-nya satu per satu sebelum menulis kode apa pun.
5. `pertamina_rig_dashboard.sql` — skema database lengkap (11 tabel) + data seed, jadi
   baseline untuk migration Laravel kamu.
6. `TASK.md` — roadmap pengerjaan 11 fase (Fase 0 sampai Fase 10). Ini urutan kerja
   yang harus kamu ikuti, satu fase per satu waktu.

**Aturan inti yang wajib kamu patuhi** (detail lengkap ada di `AGENTS.md`):

- ❌ **Jangan kerjakan lebih dari satu fase sekaligus.** Selesaikan satu fase, laporkan,
  lalu **berhenti dan tunggu izin saya** sebelum lanjut ke fase berikutnya.
- ❓ **Selalu tanya di awal setiap fase** (cek bagian "❓ Hal yang perlu dikonfirmasi" di
  `TASK.md`) dan **setiap kali menemukan hal yang ambigu** di tengah pengerjaan — jangan
  berasumsi sendiri.
- 🚫 **Jangan menambah fitur, halaman, field, atau komponen yang tidak ada di desain**
  (`desainku/` dan `DESAIN.md`), kecuali saya izinkan secara eksplisit di chat. Kalau
  kamu punya ide bagus, usulkan dulu — jangan langsung dibuat.
- 🎨 **Desain visual sudah final** — ikuti warna, font, layout, dan komponen di prototipe
  HTML persis, jangan didesain ulang dengan alasan apa pun.

Mulai sekarang dari **Fase 0 (Setup Proyek)** di `TASK.md`. Sebelum mulai, konfirmasi
dulu ke saya jawaban untuk pertanyaan "❓" di Fase 0, dan sampaikan ringkasan rencana
